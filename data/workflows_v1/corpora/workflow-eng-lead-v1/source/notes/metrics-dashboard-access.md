# Who can see the metrics dashboards - 2026-05-06

Rina asked for the whole company to get read access. I pushed back and we
landed here:

- **Engineering and PM**: full access to product dashboards.
- **Support**: access to error rate and version adoption only. Aditi's team
  needs to know whether a spike is real, not to browse.
- **Everyone else**: the weekly summary Rina posts, not the live dashboards.

This is not about secrecy. It is that a dashboard without context gets
screenshotted into a channel with a confident wrong caption, and then I spend a
morning explaining that the drop is a release cadence artefact.

Access requests go to Lena. She has the group memberships.

The dashboards themselves contain no user-identifying data, so this is an
interpretation problem rather than a privacy one.
