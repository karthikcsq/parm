# Issue labels - OLD SCHEME - retired 2026-01-30

Superseded by the issue triage rules note. Recorded because issues opened
before 2026-01-30 still carry these labels and they do not mean what the
current labels mean.

Old scheme:

- `P0` through `P3`, assigned by whoever opened the issue
- `bug`, `feature`, `chore`
- `needs-info`, applied liberally and never removed

Why it was retired: priority set by the reporter is not priority, it is
urgency-as-felt-by-one-person, and roughly 40% of open issues were `P1`. The
`needs-info` label had been applied to 200 issues and removed from about a
dozen, so it functioned as a graveyard rather than a state.

Current scheme uses `critical` as the only priority label, applied during
triage by the on-call, and everything else is a state that must be removed to
close.

If you are reading an old issue: its `P1` means nothing.
