# Release cadence - SUPERSEDED 2026-02-20

Obsolete. Current cadence is weekly; see the release checklist.

This note described the monthly release train we ran through 2025:

> Releases go out on the first Tuesday of the month. Code freeze the preceding
> Thursday. Anything that misses the freeze waits four weeks.

We moved to weekly because the four-week wait was making every decision bigger
than it needed to be. People fought to get into a train because missing it was
expensive, which meant half-finished work merged on freeze day, which meant the
release was worse.

Kept because the phrase "misses the train" still comes up in old issues and it
is not obvious to anyone who joined this year what it referred to.

Note that the freeze concept described here no longer exists in any form.
Freezes we declare now are specific and scoped, like the billing migration one,
and are announced individually.
